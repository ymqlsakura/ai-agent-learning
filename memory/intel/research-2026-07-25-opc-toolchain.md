## 主题 A：一人公司 AI 工具栈

### 海外标准栈（"7+1"）

| 层级 | 工具 | 做什么 |
|------|------|--------|
| 工程 | Claude Code / Cursor | 写代码、调试、部署——替代全职工程师 |
| 管理 | Linear | AI 自动 issue 分类和周期规划 |
| 基础设施 | Vercel + Supabase | 部署+数据库+认证——零运维 |
| 收款 | Stripe | 支付/订阅/发票全自动 |
| 研究 | Perplexity | 市场调研、竞品分析（带引用） |
| 组织层 | Soleur | 8 个 AI Agent 覆盖 8 个业务部门 |

### 中国常用栈

| 类别 | 工具 |
|------|------|
| 大模型 | DeepSeek、豆包、通义千问、Kimi |
| AI 编程 | Cursor、GitHub Copilot、Trae（字节）、Coze |
| AI 视频 | 即梦、小云雀 AI 短剧 Agent、可灵 |
| AI 图像 | Midjourney、Stable Diffusion、即梦 |
| AI Agent | OpenClaw（开源，中国爆火）、Coze 扣子 |
| 社区 | WaytoAGI 开源社区、618 个 OPC 社区 |

### 关键发现

- **Taskade** 是最完整的"一人公司 AI 工作空间"：任务+文档+知识库+自动化+34 个 AI Agent 五合一。永久免费版很慷慨。YC 支持。
- **Soleur** 提出"Company-as-a-Service"——不是更好的工具，而是覆盖 8 个业务部门的组织层 AI Agent。这可能是下一个范式。
- 海外 74% solopreneurs 使用 AI。中国 OPC 创业者几乎 100% 使用 AI。
- 中国 AI 员工成本仅为初中级工程师的 1.8%。

## 主题 B：AI Agent 框架选型

### 框架分级

| 梯队 | 框架 | 适合樱漫清澜？ | 一句话 |
|------|------|-------------|--------|
| 🥇 | **CrewAI** | ✅ 如果写代码 | Python，20 行出 Demo，角色驱动，30 分钟上手 |
| 🥇 | **Smolagents** | ✅ 如果写代码 | Hugging Face 出品，<50 行代码，极简 |
| 🥇 | **Dify** | ✅ 不写代码 | 拖拽搭 Agent，144K GitHub stars，开源免费 |
| 🥇 | **Mastra** | ✅ 如果写 TypeScript | TypeScript-first，81 个 LLM 供应商 |
| 🥈 | LangGraph | ❌ | 学习曲线 4-8 周，不适合起步 |
| 🥈 | PydanticAI | ❌ | 需要 Python 类型系统经验 |
| 🥈 | OpenAI Agents SDK | ❌ | 锁 OpenAI 生态，token 成本高 |

### 核心趋势

- **MCP 已成为行业标准**——Anthropic 捐给 Linux Foundation，OpenAI/Google/Microsoft 全部支持。月下载从 200 万飙到 9700 万。
- **80% 场景不需要 Agent 框架**——直接调 API 就够了。别为了用框架而用框架。
- **混合框架是常态**——CrewAI 做原型 → LangGraph 做生产 → Dify 做内部工具。

## 主题 C：中国 OPC 生态

### 数据

| 指标 | 数值 |
|------|------|
| 一人有限责任公司 | 1600 万+（占全部企业 27.4%） |
| 2025 上半年新增 | 286 万（同比 +47%） |
| OPC 社区 | 618 个（2026H1，从 95 个暴增） |
| 覆盖范围 | 24 省 75 市 |
| 政策 | 7 部委联合发文，OPC 首次写入国家级政策文件 |
| 广东 | 率先出台省级 OPC 政策框架（"拎脑入驻"） |

### 真实案例

| 人物 | 做什么 | 工具 | 成果 |
|------|------|------|------|
| 陈云飞 | "小猫补光灯" App | AI 编程（Cursor 类），从未写过代码 | App Store 霸榜 |
| 江海 | AI 真人微短剧《郎在月河》88 分钟 | 即梦 + AI 语音合成 | 一人完成，成本 ~1 万元 |
| 景行 | 劳动关系指导小程序 + 情绪陪伴 + 城市探索 | AI 覆盖全流程 | 月流水覆盖运营成本 |
| 武彬 | AI 电商全流程（6 家网店 AI 自主运营） | DeepSeek + 自研 | 累计 GMV 数亿元 |
| 傅江燕 | AI 多语种袜子跨境销售 | DeepSeek + AI 视频 | 年销 2000 万双 |

### 关键洞察

- 中国 OPC 走的是"个体+供应链"模式——一个人背后是义乌/东莞/苏州的全国供应链网络
- 75% 来自非技术背景
- 核心风险："单点故障"——创始人健康/判断失误 = 公司停摆
- AI 编程虽快但隐性时间成本高（监督、纠错、反复重建）

## 行动建议（3 条）

### 建议 1：注册 Taskade，体验 AI Agent 工作空间 ⭐9 分

**做什么**：taskade.com 注册（GitHub 登录即可）→ 创建一个 AI Agent → 体验它的"Genesis" Prompt-to-App 功能。

**为什么**：Taskade 是目前最完整的一人公司 AI 工作空间——五合一（任务+文档+知识库+自动化+AI Agent）。永久免费版足够日常使用。先体验，不急着决策。

**失效条件**：如果 Taskade 的 AI Agent 功能在国内网络环境下不稳定 → 转向 Coze 扣子（建议 3）。

---

### 建议 2：搜索离你最近的 OPC 社区 ⭐9 分

**做什么**：搜索"OPC 社区 [你所在城市]"或"一人公司 孵化 [城市]"→ 了解有没有就近的 OPC 社区或阿里中心 OPC 支持点。

**为什么**：618 个 OPC 社区提供免费/补贴办公空间 + 算力 + 公司注册 + 会计法务 + 客户对接。樱漫清澜不需要现在入驻，但知道"附近有什么"本身就是基础设施认知。

**失效条件**：如果最近的 OPC 社区 >100 公里 → 关注线上社区（WaytoAGI 等）。

---

### 建议 3：注册 Coze 扣子，零代码搭第一个 AI Agent ⭐8 分

**做什么**：coze.cn 注册 → 选一个模板（客服/内容生成）→ 发布到微信/飞书。全程拖拽，不写代码。

**为什么**：Coze 是国内最成熟的零代码 Agent 平台，700+ 插件，Vibe Coding 自然语言生成应用。对零编程基础的人最友好。搭配上面两个建议——Taskade 管工作空间，Coze 管 Agent 搭建，OPC 社区管基础设施。

**失效条件**：如果 30 分钟内搭不出一个可用的 Agent → 说明"零代码"宣传有水分，记录实际门槛。
