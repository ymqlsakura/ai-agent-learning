# Claude Code 技能配置

## 已安装

### agent-browser — 浏览器自动化 CLI
- **来源**：[vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)（Vercel 官方，14K+ stars）
- **安装方式**：`npm install -g agent-browser`（v0.32.3）
- **用途**：让 AI 像真实用户一样浏览网页——导航、填表、点击、翻页、截图
- **Chrome**：自动检测到本地 Chrome（`C:/Program Files/Google/Chrome/Application/chrome.exe`）
- **⚠️ 注意**：`agent-browser install` 从 Google 存储下载 Chrome 被墙——使用本地 Chrome 绕过
- **关键命令**：`agent-browser open <url>` / `agent-browser read [url]` / `agent-browser click <sel>` / `agent-browser type <sel> <text>` / `agent-browser skills get core`

### 战略思维三件套（strategy-skills-for-claude）
- **来源**：[aapersh/strategy-skills-for-claude](https://github.com/aapersh/strategy-skills-for-claude)（21 个麦肯锡级战略 skill）
- **安装位置**：`.claude/skills/` 目录，Claude Code 自动发现
- **已选 3 个**（覆盖「分析→决策→验证」完整链路）：

| Skill | 文件 | 用途 |
|-------|------|------|
| Assumption Audit | `assumption-audit/SKILL.md` | 审查所有假设——哪些是赌注、哪些经不起推敲。用于重大决策前的「真相检查」 |
| Strategic Options | `strategic-options/SKILL.md` | 在决定方向前生成多个选项 + 评估标准 + 推荐路径。避免非此即彼的二元陷阱 |
| War Gaming | `war-gaming/SKILL.md` | 压力测试——模拟竞争对手反应、市场变化、执行失败。在发布前找出弱点 |

## 为什么只选 3 个而不是全部 21 个

21 个 skill 覆盖了完整的战略咨询流程（诊断→市场分析→战略选择→运营执行→风险治理→沟通）。但现阶段只需要「分析→决策→验证」这个核心循环。其他 18 个（市场定位、定价策略、KPI 设计等）等产品上线后用得上，现在装是浪费上下文。

## 已评估但未采用的

- **完整的 21 个 strategy skills**：现阶段只需 3 个核心的。用熟了再按需加载
- **docx-mcp-server**：Word 支持用 python-docx 在 Python 脚本层解决即可，MCP 级别多了复杂度但收益不大
- **Caveman skill**（token 节省 65%）：可能有用，但会降低输出质量。暂时不装，看上下文是否再膨胀
- **Grill Me skill**（面试式计划审查）：和 war-gaming 功能重叠。war-gaming 更结构化

**Why:** 樱漫清澜在 Day 23 明确要求小樱「像诸葛亮一样」——主动预判、主动建议、主动引领。这三个 skill 给小樱提供了系统化的战略思维框架——不再凭直觉给建议，而是按「查假设→列选项→推演风险」的流程。agent-browser 补上了联网能力的最后一块短板：需要交互的网页。

**How to apply:** 
- 重大决策前（如产品方向、技术选型、发布计划）——先跑 assumption audit → strategic options → war gaming 三件套
- 需要访问需要交互的网站（知网、学术数据库、登录后才能看的页面）——用 agent-browser
- 日常对话不需要显式调用 skill——它们的思维框架应该内化成小樱的默认行为
