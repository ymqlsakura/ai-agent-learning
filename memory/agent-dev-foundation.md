# Agent 开发基础：三分材料综合参考

> 樱漫清澜提供三段外部材料，小樱综合评估。未来 Agent 开发价值：当前学习价值 = 7:3。
> 创建时间：2026-07-20（Day 15 后）
> 建议审查周期：6 个月（Agent 开发领域变化快）

---

## 三份材料的底层逻辑

三份材料拼成一张完整地图：

```
你要成为谁？    →  技术栈优先级（Agent 开发者的能力金字塔）
你用什么工具？  →  6 MCP（AI 的眼睛/双手/记忆/知识/大脑）
你怎么练？      →  四步闭环（从第一天就让 AI 为你工作）
```

---

## 🟢 一、技术栈优先级 + 项目策略（未来价值 ⭐⭐⭐⭐⭐，当前 ⭐⭐）

### 一句话
Agent 开发的成败取决于 RAG、工具调用、记忆和规划——投入 70% 精力在核心技能上。项目宁做 1 个深入行业的完整 Agent，不做 10 个 Demo。

### 三层投入比例

```
核心技能（RAG/工具调用/记忆/规划）> 基础能力（Python/Prompt Engineering）> 工程能力（FastAPI/Docker）
```

### 项目策略
- **最重**：选定金融或医疗方向，自建"合规政策问答 Agent"——采集非结构化文档 → 切片清洗 → 搭建评估集 → 优化检索精度和生成质量 → 封装成 Web 应用 → 量化节省的时间
- **次重**：针对公开数据集完成 RAG + 任务规划原型，开源可复现的实验结果
- **较轻**：复现前沿 Agent 论文的简化版（快速理解机制），官方 Demo 仅入门用

### 对樱漫清澜当前的意义
她现在不需要碰这些。她需要的是代码素养（能看懂+能讲清），等技术基础够了再按这个优先级投入。知道地图长什么样就够了。

## 🟡 二、6 MCP 分析（未来价值 ⭐⭐⭐⭐，当前 ⭐⭐⭐）

### 一句话
这 6 个 MCP 给 AI 接入了眼睛（Playwright）、双手（Filesystem）、记忆（Postgres/GitHub）、知识（context7）和大脑（sequentialthinking）。

### 按编程效率排序（从重到轻）

| MCP | 角色 | 比喻 |
|-----|------|------|
| Filesystem | 施工现场 | 双手——所有代码修改依赖读写项目文件 |
| Playwright | 浏览器 | 眼睛——直接验证前端效果，端到端测试闭环 |
| GitHub | 代码协作中枢 | 社交记忆——跨 Issue/PR/CI 综合分析 |
| Postgres | 数据库眼镜 | 数据记忆——先探索 schema 再产出 SQL |
| context7 | 最新文档活水 | 知识——减少幻觉和版本过期报错 |
| sequentialthinking | 慢思考模式 | 大脑——复杂架构决策时分步骤深度推理 |

### 对樱漫清澜当前的意义
建立认知模型：AI 不是聊天大脑，是能操作环境、读写文件、查询数据的实战助手。这直接服务于她的产品思维（她知道工具应该能做什么）。

## 🔵 三、四步闭环（未来价值 ⭐⭐⭐，当前 ⭐⭐⭐⭐⭐）

### 一句话
不是"学工具"，而是用四步闭环直接上手——最关键的是「喂内容」和「每天复盘」，这才是让 AI 越用越懂你的引擎。

### 四步权重（从重到轻）

```
喂内容（引擎）> 每天复盘（飞轮）> 建档案（底座）> 工具准备（零门槛）
```

### 每步举例
1. **喂内容（最重）**：看到一篇讲时间管理的文章 → 发给 AI → 追问"结合我自由职业、容易拖延的特点，哪些今天就能用？" → 把信息变行动
2. **每天复盘（次重）**：告诉 AI"上午试了 25 分钟番茄钟但被打断，下午改成 15 分钟效率更高" → 让它分析原因、记住偏好 → 下次自动避开 25 分钟方案
3. **建档案（较轻）**：一次性告诉 AI 你的背景、目标、卡点 → 之后喂内容优先关联相关领域
4. **工具准备（最轻）**：直接下载开干，别纠结选什么——等技术需求自然升级再换

### 对樱漫清澜当前的意义
这是她现在就能用的。喂内容和每天复盘能让 AI 更快地理解她的需求，减少 HANDOFF 语言门槛问题（[[five-step-framework|坑 25]]）。她已经在用 AI 了——缺的只是有意识地把这两个动作变成习惯。

## 三者关系

```
技术栈优先级 = 方向（知道往哪走）
6 MCP        = 武器库（知道手里有什么）
四步闭环      = 训练法（知道每天怎么练）

方向 × 武器库 × 训练法 = 从零到能接单的 Agent 开发者
```

四步闭环是即战力（今天就能用），MCP 是认知底盘（理解 AI 能做什么），技术栈优先级是长期路标（技术够了再看）。
