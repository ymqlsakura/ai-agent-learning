# MCP 工具配置

## 已配置

### Serper (google_search + scrape)
- **配置文件**：`d:\ai agent2\.mcp.json`
- **包名**：`serper-search-scrape-mcp-server`（npm，通过 `npx -y` 运行）
- **API Key**：Serper.dev（邮箱注册，2500 次免费额度，不需要绑卡）
- **工具**：
  - `google_search` — Google 搜索（需传 `q`/`gl`/`hl`，支持 num/tbs/page 等参数）
  - `scrape` — 读取网页内容并转为 Markdown（传 `url`，返回 text + metadata）
- **测试验证**（2026-07-21）：搜索"郭庆光 传播学教程"→ 3 条 Google 结果 → scrape 百度百科页面 → 读到完整图书目录（15 章）
- **Windows 注意**：必须用 `cmd /c` 包装 npx 命令

**Why:** MCP 联网能力是引用核查和竞品调研的基础设施。之前 WebFetch 被学术数据库全站拦截，WebSearch 只能拿摘要——引用核查停留在「搜到标题→标记已确认」。现在可以「搜到文献→打开页面→核实内容」。这是质的区别。

**How to apply:** 新会话启动时，MCP 工具自动加载（`.mcp.json` 已配置）。如果工具不可用，检查：① `npx` 是否可用（需 Node.js >= 18）② `SERPER_API_KEY` 环境变量是否传递 ③ 网络是否正常。
