# 音频生产流程

## 默认声音来源

默认由 Shawn 录制一条完整口播，不要求按章节开始和停止。整段录音更容易保持情绪、语速和上下文连续，后期再根据真实停顿和画面切分。

IndexTTS2 只用于本人明确授权的局部补录、修句或指定整期草稿。能快速重录时优先真人重录。不得克隆未经授权的第三方声音。

## 文件层级

```text
assets/audio/
  raw/                 原始录音，只读保存
  edit/                语义剪辑和变速候选
  cloned/              授权补录和 manifest
  final/               最终口播和混音
```

旧项目没有这些子目录时，至少保证原文件和衍生文件名称不同。任何处理都不能覆盖唯一原始录音。

## 原始录音门禁

收到录音后立即运行：

```powershell
cd D:\video\xueai-video-skills\check-video-audio
python scripts/check_audio.py "D:\path\recording.mkv" --profile recording --strict --report-json "D:\path\recording.audio-qc.json"
```

同时检查：

- 录音设备是否正确。
- 是否有啸叫、高频线、电源嗡声、削波和声道异常。
- 人声是否发闷、过小、过远或被降噪破坏。
- 音频是否完整，没有意外断录。

原始录音失败时先找输入设备、接口、驱动、监听回路和连接方式的根因。不要直接叠加强降噪掩盖硬件问题。

## 语义剪辑

1. 转写完整录音并保留时间戳。
2. 将转写与批准文案对齐。
3. 识别说错后重说、重复句、试音、咳嗽和明显过长停顿。
4. 在完整词句边界裁切，避免从词中间切开。
5. 优先选择情绪自然、意思完整的最后一次正确表达。
6. 保留让语气亲和的合理口语，不机械替换成书面稿。
7. 拼接处使用短交叉淡化并检查气口、底噪和空间感是否跳变。
8. 输出一个完整连续的候选音频给用户试听。

语义剪辑完成后用局部 ASR 检查拼接前后，防止吞词、重复和顺序错误。

## 速度和停顿

- 先完成内容剪辑，再决定整体变速。
- 常见候选是 1.05 到 1.20 倍，是否采用以自然度为准。
- 使用保持音高的变速，不允许声音变尖或机械。
- 重点句、转折、免费资料和下期预告需要保留呼吸和句后停顿。
- 不要为了追求短时长把整期压成没有起伏的一条声音。

## 清理和响度

只在诊断后选择处理。常见顺序：

1. 75 到 80 Hz 高通，处理低频震动。
2. 温和频谱降噪，处理稳定底噪。
3. 慢释放扩展，降低停顿噪声。
4. 轻度压缩，控制大小声差异。
5. 响度归一和真峰值限制。

目标以 `check-video-audio` 当前标准为准。不要把滤镜参数当成永远固定的配方。强降噪造成发闷、金属音或水声时，宁可降低处理强度。

## 口播门禁

```powershell
python scripts/check_audio.py "D:\path\narration.wav" --profile narration --strict --report-json "D:\path\narration.audio-qc.json"
```

必须同时满足：

- strict 状态为 PASS。
- 转写内容与批准文案一致，允许自然口语但不允许意思改变。
- 没有错误 take、重复、吞词和突兀剪口。
- 速度、情绪和重点符合内容。
- 用户试听并接受最终口播。

## 克隆补录

- 生成前确认本人授权、用途和替换句。
- 保存声音档案别名、模型、模式、生成时间和本地路径。
- 不把真实参考音路径写入配置或 Git。
- 逐句检查错字、多音字、英文、数字、情绪和拼接。
- 与相邻真人音频保持响度、语速、空间感和底噪一致。
- 生成成功不等于批准，完整试听后才能标记为 `approved`。

## 音乐和效果

- 背景音乐必须记录曲名、作者、来源和商用授权。
- 授权不完整时，不进入发布主片，只能保存为明确标记的非发布候选。
- 音乐不能让最终音频的静态底噪判断失真。必要时单独质检口播。
- 保持人声始终清晰，重点句可以轻度压低音乐。

## 最终成片音频门禁

```powershell
python scripts/check_audio.py "D:\path\final.mp4" --profile final --strict --report-json "D:\path\final.audio-qc.json"
```

自动门禁通过后仍需戴耳机检查一个安静停顿、最响段落、报告指出的时间点、句尾和剪口。听感与指标冲突时，以听感为准并重新处理。
